Gemini 中转 API
基于 openai-gemini 部署在 Cloudflare Workers，利用 Cloudflare 全球网络提供 OpenAI 格式的 Gemini API 代理。
配合 Chatbox 客户端即可轻松使用。
Gemini API OpenAI兼容 Cloudflare Worker
⚙️ 使用步骤
  1. 下载 Chatbox 客户端（免费，支持 Win/Mac/Linux/手机）
  2. 设置 → 选择“OpenAI API”类型
  3. API 地址填入：https://gemini.awa486.top/v1
  4. API 密钥填入你的 Google AI Studio 密钥
  5. 选择模型（如 gemini-3.1-pro-preview）开始聊天
